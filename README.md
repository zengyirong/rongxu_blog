# MY_NAME 的技术博客

基于 VitePress 的个人静态技术博客。方案与落地文档见 [`plan/`](./plan/)。

## 环境

- Node.js 22+
- pnpm

## 命令

```bash
pnpm install
pnpm docs:dev      # 本地开发 http://localhost:5173
pnpm docs:build    # 生产构建 → docs/.vitepress/dist
pnpm docs:preview  # 预览构建产物
```
