# 01 · 落地执行清单

配套总方案：[个人静态技术博客方案 V1.0](./个人静态技术博客方案%20V1.0.md)

按总方案「二十一、建议开发顺序」拆成 9 步。每步写清目标、产出、验收。个人昵称 / 简介 / 域名统一用占位符（`荣叙`、`YOUR_DOMAIN` 等），不阻塞落地。

---

## V1 做 / 不做

### 做

- VitePress + Vue 3 + TypeScript + pnpm
- Markdown 文章、分类、标签、TOC、代码高亮
- 本地全文搜索、深色模式、上一篇 / 下一篇
- 首页、关于我、项目经历、GitHub 入口
- Sitemap / 基础 SEO、响应式
- GitHub → Cloudflare Pages 自动部署、HTTPS、CDN
- Cloudflare Web Analytics（账号侧开启）
- 自定义域名（博客稳定后再绑）

### 不做（留给后续）

| 项                           | 阶段 |
| ---------------------------- | ---- |
| Giscus 评论                  | V1.1 |
| RSS / 归档 / 阅读时间 / 分享 | V1.1 |
| Cloudflare R2 图床           | V1.2 |
| 后台管理 / 数据库 / 用户系统 | V2+  |

---

## 第 1 步：项目骨架

**目标：** 本地能跑起 VitePress。

**产出：**

- `package.json`、`pnpm-lock.yaml`、`.gitignore`、根 `README.md`
- `docs/.vitepress/config.ts`、基础 theme
- Node 22+、pnpm

**验收：**

- [ ] `pnpm docs:dev` 可打开本地站点
- [ ] `pnpm docs:build` 成功，产物在 `docs/.vitepress/dist`

详见：[02-项目骨架与配置](./02-项目骨架与配置.md)

---

## 第 2 步：首页 + 导航

**目标：** 信息架构可点击到达。

**产出：**

- 顶栏：首页 / 技术文章 / 项目实践 / 关于我（+ 外链 GitHub）
- `docs/index.md` 首页名片区 + 最新文章入口
- 各栏目索引页占位

**验收：**

- [ ] 导航均可到达对应页面
- [ ] 首页展示自我介绍占位与文章入口

---

## 第 3 步：文章系统

**目标：** 写一篇 Markdown 能正确渲染与检索。

**产出：**

- `docs/posts/{frontend,engineering,architecture,ai,notes}/` 目录
- frontmatter 规范、1～2 篇示例文
- 本地搜索、侧栏 / TOC、代码高亮

**验收：**

- [ ] 示例文章有标题、日期、标签、正文、代码块
- [ ] 搜索能搜到示例文关键词
- [ ] 文章页有 TOC（标题层级足够时）

详见：[03-内容与写作规范](./03-内容与写作规范.md)

---

## 第 4 步：个人化

**目标：** 站点像「你的」博客，而不是空壳文档站。

**产出：**

- 站点标题 / Logo / favicon 占位
- 关于我页、项目实践页内容骨架
- 技术栈与 GitHub 链接占位

**验收：**

- [ ] `about`、`projects` 有可读占位文案
- [ ] 导航或页脚有 GitHub 外链（`YOUR_GITHUB`）

---

## 第 5 步：SEO

**目标：** 构建产物具备基础收录能力。

**产出：**

- `title` / `description` / OG 相关配置
- `sitemap`（`hostname` 先用占位或 pages.dev）
- `favicon`、语义化标题

**验收：**

- [ ] 构建后存在 `sitemap.xml`
- [ ] 页面 `<title>` / description 合理
- [ ] 有 favicon（可先占位）

---

## 第 6 步：GitHub

**目标：** 代码与 Markdown 进远端仓库。

**产出：**

- 仓库（建议名：`blog` / `personal-blog` / `my-blog`）
- `main` 为生产分支

**验收：**

- [ ] `git push` 到 GitHub 成功
- [ ] README 能说明如何本地开发

---

## 第 7 步：Cloudflare Pages

**目标：** push 即自动构建发布。

**产出：**

- Pages 项目连接 GitHub
- 构建：`pnpm install` + `pnpm docs:build`
- 输出目录：`docs/.vitepress/dist`
- 生产分支：`main`

**验收：**

- [ ] Production 部署成功，可打开 `*.pages.dev`
- [ ] 非 main 分支可出 Preview（可选）

详见：[04-部署与域名](./04-部署与域名.md)

---

## 第 8 步：域名

**目标：** 自定义域名（可延后到内容稳定后）。

**产出：**

- 域名接入 Cloudflare DNS
- 绑定到 Pages 项目
- 更新 `sitemap.hostname` 与站点 URL

**验收：**

- [ ] `https://YOUR_DOMAIN` 可访问且 HTTPS 正常

---

## 第 9 步：开始写内容

**目标：** 进入「学习 → 总结 → Markdown → push → 上线」循环。

**产出：**

- 真实文章持续写入 `docs/posts/**`
- 少改博客系统、多写内容

**验收：**

- [ ] 至少有若干篇真实技术文（非占位）
- [ ] 对照 [05-V1验收清单](./05-V1验收清单.md) 完成打勾

---

## 推荐推进节奏

```text
第 1～3 步（骨架 + 导航 + 示例文）→ 本地可演示
第 4～5 步（个人化 + SEO）       → 可上线形态
第 6～7 步（GitHub + CF）        → 自动部署
第 8 步（域名）                  → 可延后
第 9 步（写内容）                → 长期主线
```
