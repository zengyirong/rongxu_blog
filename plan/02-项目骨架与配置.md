## package.json scripts

建议脚本名与 Cloudflare 构建命令保持一致：

```json
{
  "scripts": {
    "docs:dev": "vitepress dev docs",
    "docs:build": "vitepress build docs",
    "docs:preview": "vitepress preview docs"
  }
}
```

常用命令：

```bash
pnpm install
pnpm docs:dev      # 本地开发
pnpm docs:build    # 生产构建
pnpm docs:preview  # 预览构建产物
```

构建输出目录（默认）：

```text
docs/.vitepress/dist
```

## `.vitepress/config.ts` 要点

### 站点基础

```ts
export default defineConfig({
  title: '荣叙 的技术博客',
  description: 'Vue / TypeScript / 工程化 / AI · 学习与项目实践',
  lang: 'zh-CN',
  cleanUrls: true,
  // 上线后改为真实域名
  sitemap: {
    hostname: 'https://YOUR_DOMAIN',
  },
})
```

### 导航 `themeConfig.nav`

```ts
nav: [
  { text: '首页', link: '/' },
  { text: '技术文章', link: '/posts/frontend/' },
  { text: '项目实践', link: '/projects/' },
  { text: '外链', link: '/links/' },
  { text: '关于我', link: '/about/' },
  { text: 'GitHub', link: 'https://github.com/YOUR_GITHUB' },
]
```

### 侧栏 `themeConfig.sidebar`

按栏目挂载，例如：

```ts
sidebar: {
  '/posts/frontend/': [
    {
      text: 'Frontend',
      items: [
        { text: '概览', link: '/posts/frontend/' },
        // 随文章增加条目，或后续改为自动生成
      ]
    }
  ],
  '/posts/engineering/': [/* ... */],
  '/projects/': [
    { text: '项目实践', items: [{ text: '概览', link: '/projects/' }] }
  ]
}
```

### 本地搜索

```ts
themeConfig: {
  search: {
    provider: 'local'
  }
}
```

### 深色模式

VitePress 默认主题自带外观切换（浅色 / 深色 / 跟随系统），无需额外依赖。可按需设置：

```ts
themeConfig: {
  appearance: true // 默认即为 true
}
```

### 社交 / 页脚（可选）

```ts
themeConfig: {
  socialLinks: [
    { icon: 'github', link: 'https://github.com/YOUR_GITHUB' }
  ],
  footer: {
    message: '基于 VitePress 构建',
    copyright: 'Copyright © 荣叙'
  }
}
```

## 主题入口

`docs/.vitepress/theme/index.ts`：

```ts
import DefaultTheme from 'vitepress/theme'
import './style.css'

export default DefaultTheme
```

V1 以默认主题 + 少量 CSS 变量微调为主，不做大改版。自定义组件放在 `theme/components/`，需要时在 Markdown 中引用或在 theme 中注册。

## 初始化参考命令

若从空仓库搭骨架（本仓库落地时按实际脚本执行）：

```bash
pnpm create vitepress
# 或手动：pnpm add -D vitepress vue typescript
```

选定 `docs` 作为文档根目录，与上述目录树对齐。

## pnpm 11 注意

本仓库使用 pnpm 11。依赖构建脚本白名单写在根目录 `pnpm-workspace.yaml`：

```yaml
allowBuilds:
  esbuild: true
```

首次在新环境安装若提示 ignored builds，确认该文件已提交，或执行 `pnpm approve-builds`。

| Cloudflare 配置项      | 值                     |
| ---------------------- | ---------------------- |
| Install command        | `pnpm install`         |
| Build command          | `pnpm docs:build`      |
| Build output directory | `docs/.vitepress/dist` |
| Production branch      | `main`                 |

详见：[04-部署与域名](./04-部署与域名.md)
