```text
docs/posts/frontend/
├── index.md
├── javascript/
├── typescript/
└── vue/
    └── vue3-reactivity.md
```

文章 URL 示例：`/posts/frontend/vue/vue3-reactivity`

## 文件命名

- 使用小写英文 + 连字符：`vue3-reactivity.md`
- 避免空格与中文文件名（利于 URL 与跨平台）
- 一篇一文一个文件；系列文可用前缀：`rbac-01-overview.md`

---

## Frontmatter 约定

每篇文章文件头部：

```yaml
---
title: Vue3 响应式原理
description: 梳理 reactive、track、trigger 与依赖收集。
date: 2026-08-07
category: frontend
tags:
  - Vue
  - 响应式
outline: deep
---
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 文章标题（也用于 SEO） |
| `description` | 建议 | 摘要，用于列表与 meta |
| `date` | 建议 | `YYYY-MM-DD`，排序与展示 |
| `category` | 建议 | `frontend` / `engineering` / `architecture` / `ai` / `notes` / `projects` |
| `tags` | 建议 | 字符串数组 |
| `outline` | 可选 | TOC 深度，如 `deep` |

VitePress 也会识别部分内置 frontmatter（如 `title`、`description`）。自定义字段可在后续主题组件中读取。

## 正文结构建议

```markdown
# 标题（可与 frontmatter title 一致，或省略 H1 只用 frontmatter）

## 背景

一两段说明问题从哪来。

## 结论先行（可选）

读者 30 秒内能拿走的要点。

## 正文

分节展开，代码块注明语言：

\`\`\`ts
export function example() {}
\`\`\`

## 踩坑 / 注意点

## 参考

- 链接或文档名
```

原则：

- 一个问题一篇文，避免「大而全」长文堆砌
- 代码可运行或可对照；删掉与主题无关的噪音
- 配图放 `docs/public/images/...`，文中用根路径引用

## 图片

存放：

```text
docs/public/images/<topic>/xxx.png
```


头像等：

```text
docs/public/avatar/me.png
```

V1 不使用 R2；图随 Git 管理即可。

## 栏目索引页

每个栏目根目录建议有 `index.md`，例如 `docs/posts/frontend/index.md`：

```markdown
---
title: Frontend
description: 前端相关文章
---

# Frontend

- [Vue3 响应式原理](./vue/vue3-reactivity)
```

项目与关于页同理：`docs/projects/index.md`、`docs/about/index.md`。

## 示例文章模板

复制为新文件后改 frontmatter 与正文：

```markdown
---
title: 文章标题
description: 一句话摘要。
date: 2026-08-07
category: frontend
tags:
  - TagA
  - TagB
outline: deep
---

## 背景

说明上下文。

## 要点

1. 要点一
2. 要点二

## 示例代码

\`\`\`ts
const msg = 'hello'
console.log(msg)
\`\`\`

## 小结

今天解决了什么、下次要注意什么。
```

## 首页「最新文章」

V1 可用手动列表维护在 `docs/index.md`；文章多了再考虑脚本或主题侧自动聚合。新增重要文章时，记得同步更新首页链接。

## 写作工作流

```text
学习 / 排障 / 项目
    ↓
按栏目选目录
    ↓
复制模板 → 填 frontmatter → 写正文
    ↓
pnpm docs:dev 本地预览
    ↓
git commit & push
    ↓
Cloudflare Pages 自动上线
```
