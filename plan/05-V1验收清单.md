## E. 完成定义（DoD）

当同时满足时，可认为 **V1 骨架验收通过**：

1. 本地 `docs:dev` / `docs:build` 正常
2. 导航与示例内容齐全，搜索与深色模式可用
3. A 表中除「自定义域名 / Analytics / 自动部署」外的站点能力已勾选（后三项依赖账号时可标「延后」）
4. 内容写作按 [03](./03-内容与写作规范.md) 可持续新增

当再满足：

5. GitHub → Cloudflare Pages 自动部署成功

则认为 **V1 上线验收通过**（域名可另计）。
