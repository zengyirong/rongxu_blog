## 一、项目定位

### 1. 核心目标

建设一个属于自己的个人技术博客，用来长期沉淀：

- 前端技术学习
- Vue / TypeScript
- JavaScript
- 前端工程化
- Node.js
- AI + 编程
- 项目实践
- 问题排查记录
- 面试知识整理
- GitHub 项目记录

博客定位不是“大而全的博客系统”，而是：

> **内容优先 + 极简维护 + Git 管理 + 自动部署。**

因此 V1 阶段：

```text
不做后台管理系统
不做数据库
不做传统后端服务
不做用户系统
不做复杂权限
```

文章直接使用 Markdown 管理。

# 三、技术选型

## 1. 博客框架

### VitePress

推荐使用：

```text
VitePress
Vue 3
TypeScript
```

原因：

- Vue 官方生态
- 基于 Vite
- Markdown 原生支持
- 构建后是静态 HTML
- 性能很好
- SEO 比普通纯 SPA 更合适
- 可以直接在 Markdown 中使用 Vue 组件
- 可以高度自定义主题
- 不需要后端
- 非常适合程序员技术博客

当前 VitePress 官方 Getting Started 推荐 Node.js 22+。

# 九、搜索功能

直接使用 VitePress 内置本地搜索。

VitePress 当前自带基于 minisearch 的浏览器端模糊全文搜索，可以直接配置：

```ts
themeConfig: {
  search: {
    provider: 'local'
  }
}
```

不需要：

```text
Elasticsearch
数据库
搜索服务器
后端接口
```

即可全文搜索文章。

# 最终技术选型

| 模块 | 方案 |
|---|---|
| 博客框架 | VitePress |
| 前端 | Vue 3 + TypeScript |
| 内容 | Markdown |
| 包管理 | pnpm |
| Node | Node 22+ |
| 数据存储 | GitHub |
| 图片 | public，后期 R2 |
| 搜索 | VitePress Local Search |
| 评论 | Giscus，第二阶段 |
| 统计 | Cloudflare Web Analytics |
| SEO | VitePress Sitemap + Meta |
| Git | Git |
| 代码托管 | GitHub |
| CI/CD | Cloudflare Pages Git Integration |
| 部署 | Cloudflare Pages |
| CDN | Cloudflare |
| HTTPS | Cloudflare |
| DNS | Cloudflare |
| 域名 | 自定义域名 |
| 后端 | 不需要 |
| 数据库 | 不需要 |
| 后台管理 | 不需要 |

**一句话总结：**

> 用 VitePress 做博客本体，Markdown 作为文章数据，GitHub 负责代码和内容版本管理，Cloudflare Pages 负责自动构建、部署、CDN 和 HTTPS，第一阶段完全不引入后端和数据库。
